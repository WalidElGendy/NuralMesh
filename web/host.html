FAQ

What bandwidth do I need?

A stable 50 Mbps connection is enough for beta; lower latency improves routing score.

Can I run multiple nodes?

Yes. Each machine claims its own token and appears separately in the dashboard.

What data passes through my GPU?

Inference prompts and model outputs. Sensitive customer metadata stays on MeshNet control services.

Can users see my IP?

No. Users talk to MeshNet APIs; provider addresses are not exposed to end users.

What if power dies mid-job?

The backend marks the heartbeat stale, requeues the job, and the node resumes when power returns.

When do I get paid?

Beta payouts are processed manually within 7 days of month-end. Stripe Connect is coming post-beta.
